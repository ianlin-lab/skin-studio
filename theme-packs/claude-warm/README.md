# Claude Warm

一套可直接导入 Skin Studio 的浅色主题包，侧重 Claude 式暖米白色调、陶土橙强调色和纸张感。

## 导入

1. 启动 Skin Studio。
2. 点击“导入”。
3. 选择“项目文件夹”。
4. 选择当前 `claude-warm` 文件夹。
5. 导入后选择 “Claude Warm”，点击“应用到 Codex”。

主题使用本机字体，不包含或下载第三方字体文件：

- 导航、输入框和弹窗：系统无衬线字体。
- 首页和对话正文：优先使用 macOS 的 Iowan Old Style；中文回退到宋体。
- 代码区域：保留 Codex 原有等宽字体。
